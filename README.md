# Снежный город

Новогодний 3D-город: каждый подписчик TikTok получает свой дом.

## Что лежит в папке

| Файл | Зачем |
|---|---|
| `index.html` | Весь сайт: город, интерфейс, поиск |
| `followers.json` | Жители города (только ник и дата подписки) |
| `update.html` | Страница для обновления: перетащил архив, скачал новый список |
| `update-city.mjs` | То же самое из терминала (по желанию) |
| `vercel.json` | Чтобы новые жители появлялись сразу, без старого кэша |
| `.gitignore` | Не даёт случайно выложить архив TikTok с личными данными |

## Первый запуск на Vercel (один раз)

1. Зарегистрируйся на github.com и vercel.com (на Vercel можно войти через GitHub).
2. На GitHub нажми **New repository**, назови его `snezhny-gorod`, нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file** и перетащи туда все файлы из этой папки. Нажми **Commit changes**.
4. На Vercel нажми **Add New → Project**, выбери репозиторий `snezhny-gorod`, нажми **Deploy**. Никаких настроек менять не нужно.
5. Через минуту Vercel покажет ссылку вида `snezhny-gorod.vercel.app`. Это твой город.
6. Поставь эту ссылку в профиль TikTok.

## После каждого ролика (5 минут, без Claude и без терминала)

1. TikTok: Настройки → Аккаунт → Скачать данные → «Профиль и настройки», формат JSON → «Запросить данные». Когда архив готов, скачай его.
2. Открой `твой-сайт.vercel.app/update.html`, перетащи туда скачанный архив (zip целиком или файл `user_data_tiktok.json`).
3. Страница покажет, сколько новых жителей и сколько отписались. Нажми **Скачать followers.json**.
4. На GitHub: твой репозиторий → **Add file → Upload files** → перетащи `followers.json` → **Commit changes**. Через минуту город обновится.
5. Архив и `user_data_tiktok.json` с компьютера можно удалить. На GitHub их не загружай.

Страница update.html всё считает у тебя в браузере, архив никуда не отправляется. `update-city.mjs` делает то же самое из терминала, он нужен только если тебе так удобнее.

## Особые здания

Первые 100 жителей получают особые здания автоматически: 31 тип домов и бизнесов, перемешанных так, что одинаковые не стоят рядом. Начиная с №101 здание тоже выпадает случайно, но навсегда за этим номером: примерно каждому четвёртому достаётся бизнес (пекарня, пиццерия, ресторан, магазин шляп и так далее), каждому двенадцатому — необычный дом (особняк, замок, изба, иглу…), остальным — обычный дом со своими деталями: ставни, крыльцо, мансарда, балкон, венок, снеговик, санки, олень. Порог первой сотни меняется в начале `index.html` (`FIRST_SPECIAL`), доли и наборы — в `autoType`, `BIZ_POOL` и `FANCY_POOL`.

### Редактор домов

Проще всего менять дома в редакторе: открой `адрес-сайта/edit.html`.

1. Найди жителя по нику, выбери здание и, если хочешь, свой цвет стен и крыши.
2. Нажми «Посмотреть в городе». Откроется город с изменениями, их видишь только ты.
3. Нажми «Скачать followers.json» и загрузи файл на GitHub (Add file → Upload files → Commit changes).

Сайт меняется только после загрузки на GitHub, а доступ туда есть только у тебя. Если кто-то откроет edit.html, он сможет лишь скачать файл себе. Неотправленные правки хранятся в твоём браузере, пока ты их не сбросишь.

Одинаковые здания рядом не ставятся: если у соседа по кварталу уже есть такая же кофейня, житель автоматически получает другое здание того же рода. Здания, выданные вручную, это правило не трогает.

Жители до №69 сохраняют здания, которые уже получили. Новые типы (белый дом, ёлочные игрушки, шляпы, столовая, ресторан) раздаются начиная с №70, но любому можно выдать их через редактор.

## Районы

Город сам делится на районы — ничего настраивать не надо. В центре «Ёлочный центр»,
дальше кольца по 7 улиц, каждое разрезано на 4 стороны света. Названия идут по порядку:
Пряничный квартал, Мандариновая слобода, Снегириный конец, Варежкин двор, Ледяные холмы,
Северное сияние, Хрустальный бор, Сугробово, Метелица, Оленьи луга, Морозные пруды,
Звёздная гавань, Шишкин лес, Каминная сторона, Санный спуск, Совиная роща и дальше.
Новые районы появляются сами, когда город растёт.

- Внизу всплывает плашка «📍 район · сколько жителей», когда камера перелетает в другой район.
- На карте города (кнопка с картой внизу) подписаны все районы, а под картой их список — нажал, и камера летит туда.
- В карточке дома после адреса написан район.
- Для скорости телефон строит подробные дома только в районах рядом с камерой, а дальние
  показывает простыми коробочками. Улетел — район выгружается из памяти. Поэтому даже
  35 000 жителей открываются на одном сайте примерно за полторы секунды, отдельные сайты не нужны.

## Быстродействие

Город рассчитан на десятки тысяч жителей и в первую очередь на телефоны.

- Мелкие детали домов (окна, двери, гирлянды, вывески, фонари, сугробы) собираются только для кварталов рядом с камерой и выбрасываются, когда камера улетает. Поэтому память не растёт вместе с городом.
- Дальние дома рисуются простыми коробками со снежной крышей, а совсем далёкие кварталы, утонувшие в дымке, не рисуются вовсе.
- На телефонах мелкие круглые детали проще, подробные ёлки только вблизи, чёткость экрана чуть ниже.
- Если телефон всё равно не успевает (меньше ~26 кадров в секунду), сайт сам по шагам отключает свечение, потом тени, потом снижает чёткость. Телефон это запоминает: в следующий раз город сразу откроется облегчённым, без рывков в первые секунды. Галочка «Максимальное качество» в настройках это отключает.
- Таблички школ, больниц, ТЦ и других мест рисуются только когда попадают в кадр и выбрасываются, когда долго не видны.
- Дальний дом рисуется одним куском (стены + крыша), похожие детали разного цвета — одним вызовом, а тени пересчитываются только когда камера сдвинулась.
- Если телефон всё-таки отобрал у страницы видеокарту (белый экран вместо города — бывает при куче открытых вкладок или после долгого фона), сайт сам перезагружает город облегчённым. Если это повторяется, просит закрыть лишние вкладки.

На 54 000 жителей (ноябрь 2026) в режиме телефона: вызовов отрисовки на 35–40% меньше, треугольников на 25–35% меньше, кадр считается примерно на 40% быстрее, а картинки табличек занимают 18 МБ памяти вместо 136 МБ.

Раньше, на 21 000 жителей, в режиме телефона кадр считается примерно в 2 раза быстрее, чем раньше, треугольников в кадре в 2,3 раза меньше, а деталей в памяти в 4–5 раз меньше.

## Как устроены номера

- Номер жителя даётся по дате подписки и больше не меняется. Новые подписчики получают следующие номера. Дома идут кольцами от ёлки в центре, кварталы со школами, университетами и ТЦ пропускаются.
- Кто отписался, остаётся в списке с пометкой `left`, но дома у него нет: пустых домов в городе не бывает, остальные дома сдвигаются на освободившиеся места. Из-за этого адрес (улица и номер дома) может поменяться, а номер жителя остаётся прежним.
- Скрытые аккаунты без ника получают дом с номером, но без имени.

## Открытия и места города

В центре стоит ёлка, слева от неё мэрия (мэр города — dikoanimation, имя задаётся в начале `index.html`, `MAYOR`), справа каток (открывается на 25 жителях). Перед ёлкой Снежный парк (открывается на 100 жителях): колесо обозрения, ледяная горка, беседка, ярмарочные домики, ледяные скульптуры и снеговики.

Кнопка с камерой внизу запускает прогулку по улицам: камера начинает с улицы прямо там, куда ты сейчас смотришь, проезжает её, потом переходит на соседнюю улицу и так дальше, сверху показано название улицы, сколько на ней жителей и бизнесов. Выйти — крестик справа вверху.

Дальше по всему городу, примерно через каждые 7 кварталов, стоят школы, больницы, университеты и торговые центры, чтобы рядом с каждым жителем что-то было. Место открывается, когда город дорастает до него: пока жителей не хватает, там стройка с краном и табличкой «откроется на N жителях». Ближайшая стройка — это и есть следующая цель на гирлянде вверху.

Кнопка с картой внизу открывает карту города — вид сверху: районы разными цветами с подписями, значки школ, больниц, вузов и ТЦ, красная точка — где ты сейчас. Нажми в любое место карты, и камера полетит туда. Карту можно двигать пальцем, приближать щипком или кнопками +/−, кнопка с прицелом показывает, где ты. Под картой — список мест: мэрия, школы, больницы, университеты, торговые центры, каток, Снежный парк и ближайшая стройка. Нажми на строку, и камера перелетит туда; повторное нажатие покажет следующую школу (университет, ТЦ). По месту можно и просто кликнуть в городе.

Чередование мест задаёт список `LM_KINDS` в начале `index.html` (сейчас школа, ТЦ, больница, школа, университет), расстояние между ними — `LM_STEP`, названия торговых центров — `MALL_NAMES`. Если поменять `LM_STEP`, места переедут, а вместе с ними сдвинутся адреса жителей.
