# Снежный город

Новогодний 3D-город: каждый подписчик TikTok получает свой дом.

## Что лежит в папке

| Файл | Зачем |
|---|---|
| `index.html` | Весь сайт: город, интерфейс, поиск |
| `followers.json` | Жители города (только ник и дата подписки) |
| `update.html` | Страница для обновления: перетащил архив, скачал новый список |
| `update-city.mjs` | То же самое из терминала (по желанию) |
| `vercel.json` | Чтобы новые жители появлялись сразу, без старого кэша |
| `.gitignore` | Не даёт случайно выложить архив TikTok с личными данными |

## Первый запуск на Vercel (один раз)

1. Зарегистрируйся на github.com и vercel.com (на Vercel можно войти через GitHub).
2. На GitHub нажми **New repository**, назови его `snezhny-gorod`, нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file** и перетащи туда все файлы из этой папки. Нажми **Commit changes**.
4. На Vercel нажми **Add New → Project**, выбери репозиторий `snezhny-gorod`, нажми **Deploy**. Никаких настроек менять не нужно.
5. Через минуту Vercel покажет ссылку вида `snezhny-gorod.vercel.app`. Это твой город.
6. Поставь эту ссылку в профиль TikTok.

## После каждого ролика (5 минут, без Claude и без терминала)

1. TikTok: Настройки → Аккаунт → Скачать данные → «Профиль и настройки», формат JSON → «Запросить данные». Когда архив готов, скачай его.
2. Открой `твой-сайт.vercel.app/update.html`, перетащи туда скачанный архив (zip целиком или файл `user_data_tiktok.json`).
3. Страница покажет, сколько новых жителей и сколько отписались. Нажми **Скачать followers.json**.
4. На GitHub: твой репозиторий → **Add file → Upload files** → перетащи `followers.json` → **Commit changes**. Через минуту город обновится.
5. Архив и `user_data_tiktok.json` с компьютера можно удалить. На GitHub их не загружай.

Страница update.html всё считает у тебя в браузере, архив никуда не отправляется. `update-city.mjs` делает то же самое из терминала, он нужен только если тебе так удобнее.

## Особые здания

Любому жителю можно поставить особое здание. Открой `followers.json` на GitHub, нажми карандаш и добавь жителю поле `house`:

```
{ "n": 2, "name": "kapitan_kaktus", "date": "...", "house": "doner" }
```

| `house` | Что будет |
|---|---|
| `big` | Большой двухэтажный дом с ёлками у входа |
| `mansion` | Особняк: три этажа, крылья, колонны с гирляндами |
| `doner` | Донерная: витрина, полосатый козырёк, светящаяся вывеска с ником и крутящийся вертел на крыше |

Цвет стен и крыши можно задать полями `color` и `roof`, например `"color": "#f4f6fb", "roof": "#2f3b63"`. Номер и адрес жителя не меняются. Страница update.html эти поля сохраняет, так что при обновлении города здания остаются.

## Как устроены номера

- Номер жителя даётся по дате подписки и больше не меняется. Новые подписчики получают следующие номера.
- Кто отписался, остаётся в списке с пометкой `left`: его дом стоит на месте, но пустой, с табличкой «свободно». Так у остальных не сдвигаются адреса.
- Скрытые аккаунты без ника получают дом с номером, но без имени.

## Открытия

На 25 жителях открывается каток, на 100 — ёлочная ярмарка. Дальше в планах горка (500), стадион (1 000) и ледяной дворец (5 000). Пороги меняются в начале `index.html`, в списке `UNLOCKS`.
