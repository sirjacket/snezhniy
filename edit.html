Как выложить изменения

  1. Нажми «Посмотреть в городе»: откроется город с твоими изменениями. Их видишь только ты, на сайте пока всё по-старому.
  2. Если всё нравится, нажми «Скачать followers.json».
  3. На GitHub открой репозиторий, Add file → Upload files, перетащи файл и нажми Commit changes. Если файл скачался как «followers (1).json», сначала переименуй его в followers.json.

Поменять сайт можно только загрузкой на GitHub, а доступ туда есть только у тебя. Даже если кто-то откроет эту страницу, он сможет лишь скачать файл себе. Правки, которые ты ещё не выложил, хранятся в этом браузере.
